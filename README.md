# Marketer Rajib 10 Portfolio

## GitHub Pages upload
1. Open your GitHub repository: `MarketerRajib10-portfolio`
2. Upload `index.html` to the repository root.
3. Commit changes.
4. Open Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: `main` and folder `/root`.
7. Save.
8. Your website will appear on your GitHub Pages URL.

## Edit later
- Replace the profile placeholder inside the `.avatar` block with your real photo.
- Replace project preview blocks with your Behance/project images.
- Edit package prices in the Pricing section.
- All contact links are already added.
